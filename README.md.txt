# 🚗 AI Driver Drowsiness Detection System

## 📌 Overview
A real-time driver drowsiness detection system using CNN and OpenCV.
The system detects eye state (openclosed) from webcam feed and triggers an alarm if drowsiness is detected.

## 🧠 Features
- CNN-based eye classification
- Real-time webcam detection
- Confidence score display
- FPS counter
- Alert system with sound
- Drowsiness progress bar

## 🛠 Tech Stack
- Python
- TensorFlow  Keras
- OpenCV
- NumPy
- Pygame
